# Security policy

## Supported versions

No CLI version has been released yet. During the source preview, security fixes are made on the latest `main` branch. Once releases begin, this page will identify the supported versions.

## Report a vulnerability

Email `security@koldera-accessibility.dev`. Please do not open a public issue for a vulnerability. Include the CLI commit or version, the command you ran, what you expected and what happened. A minimal synthetic example is useful; do not send customer documents, tokens or signed URLs.

Credential handling, signed upload/download URLs, redirect handling, output file safety and release workflows are in scope. If the problem is in the Koldera Core server, say so in the report so it can be routed to the right project.
